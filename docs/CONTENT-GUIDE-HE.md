# מדריך עריכת תוכן — אתר La Skin

האתר סטטי: אין מערכת ניהול תוכן. כל טקסט שמופיע באתר נמצא בקובץ אחד לכל שפה, ואחרי שינוי מריצים
בנייה ומפרסמים. אין צורך לגעת בעיצוב.

## איפה הטקסטים

| שפה | קובץ |
| --- | --- |
| עברית (נוסח המקור) | `src/i18n/he.ts` |
| ערבית | `src/i18n/ar.ts` |
| אנגלית | `src/i18n/en.ts` |

בכל קובץ אותם שדות, לפי סדר הופעתם באתר:

| שדה | איפה זה מופיע |
| --- | --- |
| `meta` | כותרת הדפדפן ותיאור לגוגל, לכל עמוד |
| `hero` | הכותרת הראשית, שורת ההבטחה, פסקת המשנה והשורה הקטנה מתחת לכפתורים |
| `lead` | טופס "רוצים לדעת עוד?" — תוויות, הודעות שגיאה, הודעת ההצלחה |
| `pillars` | הפס הכהה "מאות לקוחות מרוצים" וארבעת הכרטיסים |
| `welcome`, `tech`, `clinic` | הסקשנים 01–03 |
| `midcta` | הפס הכהה "יש שאלה לפני שקובעים?" |
| `care` | כרטיסי "הכנה" ו"מעקב" |
| `faq` | חמש השאלות והתשובות |
| `reviews` | שלוש הביקורות מגוגל |
| `contact` | כרטיס יצירת הקשר וכרטיס "איך מגיעים" |
| `areas`, `loc` | עמוד היישובים ועמוד מבשרת ציון |
| `studies` | עמוד המחקרים הקליניים |
| `legal` | מדיניות פרטיות והצהרת נגישות (כולל תאריך העדכון — לעדכן בכל שינוי) |
| `footer`, `nav` | תחתית האתר ותפריט הניווט |

עובדות עסקיות (טלפון, מייל, כתובת, שעות, קישור פייסבוק, הודעות הוואטסאפ) נמצאות ב־`src/data/site.ts`.
רשימת היישובים: `src/data/localities.ts`. המקורות המדעיים: `src/data/studies.ts`.

## תמונות

- תמונות הקליניקה: `src/assets/img/`. להחלפת תמונה — שומרים קובץ באותו שם (או מעדכנים את ה־import
  בעמוד המתאים). האתר מייצר לבד גרסאות AVIF/WebP בכל הגדלים.
- צילומי הוואטסאפ: `src/assets/img/wa/`. לכל צילום יש תמלול בשלוש שפות בקובץ `src/data/waShots.ts` —
  זה הטקסט שקורא מסך מקריא, חובה לעדכן אותו כשמחליפים צילום. לפני פרסום צילום חדש: לחתוך את כותרת
  השיחה (שם ותמונת פרופיל) ולוודא שיש הסכמה בכתב מהלקוח/ה.
- לוגו: `src/assets/img/logo-mark.png` (עיגול נקי, רקע שקוף). פביקון ותמונת שיתוף: `public/`.

## איך מפרסמים שינוי

```
npm ci            # פעם אחת
npm run check     # בדיקת שגיאות
npm run build     # בנייה לתיקיית dist/
npm test          # בדיקות תוכן וניגודיות
```

ואז `git commit` + `git push` — ה־workflow ב־GitHub בונה ומפרסם אוטומטית (כשהפריסה מופעלת).
לחלופין מעלים את תוכן `dist/` לשרת.

## כללים חשובים

1. **טענות רפואיות ותוצאות** — כל משפט על כאב, תוצאות, אישורים רגולטוריים או גיל מינימלי הוא באחריות
   בעלת העסק. לשמור אסמכתאות.
2. **ביקורות** — רק ביקורות אמיתיות, בלי שמות מלאים או פרטים מזהים של לקוחות.
3. **תאריך "עודכן לאחרונה"** במדיניות הפרטיות ובהצהרת הנגישות (`legal.updated`) — לעדכן בכל שינוי בהן.
4. לא למחוק שדות — שלוש השפות חייבות להכיל את אותם שדות (יש בדיקה אוטומטית שנכשלת אחרת).
